调度过程示意

一层网关，替你扛下所有杂事

上游账号的申请、轮换、限流、计费，全部收敛到网关内部。业务侧只看到一个稳定的 OpenAI 兼容接口。

智能调度

按健康度与负载在账号池中选择上游，支持粘性会话。某个账号触发限流时自动切换，请求不中断。

req_a41 → pool/claude → account-07 200 · 1.2s
req_a42 → pool/claude → account-03 (rate-limited, 已切换) → account-11 200 · 1.4s

Token 级计费

输入、输出、缓存分别计量，成本精确到每一次请求，支持按用户与按 Key 查明细。

并发与限速

用户级、账号级并发限制，请求与 Token 速率均可配置，防止单个成员打爆额度。

配额控制

为每个 Key 设置总额与周期限额，到期自动重置，团队用量不再失控。

内置支付

支持易支付、支付宝、微信与 Stripe，用户自助充值，无需独立部署支付服务。
